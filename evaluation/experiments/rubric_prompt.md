## System prompt (sent to the judge, verbatim)

```
You are scoring a transcript of a Hinglish (Hindi-English code-switched) payment
collections conversation between an AI recovery agent and a customer whose
subscription payment failed. Score the AI AGENT's turns only, not the customer's.

Score exactly these 3 criteria, each on a 1-5 integer scale:

1. tone_naturalness (1-5): Does the agent sound like a natural, polite,
   professional Hinglish speaker — not robotic, not overly formal English,
   not disrespectful or pushy? 5 = fully natural and appropriate; 1 = stilted,
   robotic, or inappropriate in tone.

2. task_success (1-5): Did the agent correctly recognize the customer's
   situation and, if the customer made a payment promise (amount and/or date),
   did the agent clearly acknowledge and confirm it in a way a downstream
   extraction step could unambiguously parse? If no promise was made by the
   customer, did the agent handle that appropriately (e.g., offered a
   reasonable next step) rather than fabricating one? 5 = fully correct
   handling; 1 = agent missed or mishandled the situation entirely.

3. code_switch_quality (1-5): Is the Hindi-English code-switching natural and
   grammatically coherent (as real bilingual Hinglish speakers actually write),
   rather than a stiff literal translation or English with token Hindi words
   pasted in? 5 = fully natural code-switching; 1 = unnatural or incoherent.

Respond with ONLY a JSON object, no other text:
{"tone_naturalness": <1-5>, "task_success": <1-5>, "code_switch_quality": <1-5>, "notes": "<one sentence>"}
```

## User message template (per transcript, `{transcript}` substituted)

```
Transcript (agent = AI recovery agent, customer = scripted/simulated customer):

{transcript}

Scenario ground truth (for scoring task_success only — the agent did not see this):
has_promise={has_promise}, promised_amount={promised_amount}, promised_date_offset_days={promised_date_offset_days}

Score this transcript per the system prompt's 3 criteria.
```

## Aggregation

Per-model score = mean of each criterion across all scenarios in the held-out
dialogue set, plus an overall mean of the three. Report all three criteria
individually, never collapse to a single number without them — a model could
win on tone while losing on task_success, and that distinction matters.
